# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of Trust Beacon.

| Version | Supported |
|---|---|
| 1.1.x | Yes |
| Earlier versions | No |

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
**Security** tab to submit a private vulnerability report to the maintainers.
Include affected versions, reproduction steps, potential safety impact, and any
suggested mitigation. We will acknowledge a report within five business days
and coordinate disclosure after a fix is available.

Trust-indicator failures can have physical privacy consequences. If a failure
is detected in an integration, disable camera capture until the issue has been
investigated and remediated.
